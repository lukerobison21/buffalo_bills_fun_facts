# Buffalo Bills Fan Tracker

A fan-made website for browsing a curated sample of Buffalo Bills players, saving favorites, and counting down to the next game listed in the 2026 schedule.

## Features

- Random player spotlight on the home page
- Countdown to the next listed game, with kickoff time shown in your local time
- Search players by name, position, or jersey number
- Filter players by position
- Add or remove favorite players
- Save favorites in your browser using local storage
- Responsive layout with keyboard-accessible navigation

## Run locally

No build tools or dependencies are required. Download or clone the repository, then open `index.html` in a web browser.

## Project files

- `index.html` — Home page and game countdown
- `players.html` — Player browser, search, and filters
- `app.js` — Player data, schedule, countdown, and favorites
- `styles.css` — Page styling and responsive layouts
- `images/` — Team and player images

## Keeping information current

The player list and 2026 game schedule are static examples maintained in `app.js`; they are not live data. Check the [official Bills roster](https://www.buffalobills.com/team/players-roster/) and [official Bills schedule](https://www.buffalobills.com/schedule/) for current information.
